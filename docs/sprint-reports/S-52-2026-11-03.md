# Отчёт S-52 — Spaced-repetition тренажёр

**Дата:** 2026-11-03 · **Этап:** E-19 · **Ветка:** main (автономный режим)

## 1. Что сделано

- **Схема.** Миграция `0027_review`:
  - `review_cards` (source_type/ref, front/back, ease, interval_days,
    repetitions, lapses, due_at, suspended);
  - `review_events` (rating/quality, интервалы до/после, ease).
- **SM-2.** `again` → interval 1, repetitions 0, lapses+1; `good` →
  1/6/interval×ease; ease ≥ 1.3; `review_events` — аудит ответов.
- **Очередь.** `/review/queue` — due_at ≤ now, порядок due_at/id, дневной
  лимит `REVIEW_DAILY_LIMIT` (20); `/review/stats` — due/сегодня/удержание.
- **Интеграции.**
  - failed Python-сабмит → карточка `py:{assignmentId}` (тема/тест);
  - chess-blunder → до 5 карточек `chess:{gameId}:{ply}` (FEN/лучший ход);
  - дедупликация по `(user, source_type, source_ref)`.
- **API/UI.** `POST /review/cards`, `POST /review/cards/{id}/answer`,
  `GET /review/queue|stats`; UI `/review` с показом ответа и 4 оценками.
- **Данные.** PostgreSQL; переживают рестарт; events не теряются.

## 3. Что не сделано / блокеры

- **Напоминания** не отправляются отдельным cron: карточки появляются в
  очереди; Telegram kind `review` можно ставить через outbox, но триггера
  «пора повторить» пока нет.
- **Полнотекстовый поиск/картинки** в карточках не поддерживаются.
- **Ручное редактирование/удаление** карточек — только API create/answer;
  UI создания карточки нет.
- **Chess-карточки** создаются только после завершённого анализа партии
  (worker); при выключенном worker — позже.
- **Дневной лимит** ограничивает выдачу, но не блокирует ответы по старым
  карточкам.

## 4. Отклонения от Design

- SM-2 хранит `interval_days` целым, без часовых интервалов: первый
  повтор — 1 день.
- `source_ref` — строка, уникальность в рамках пользователя; manual-карточки
  без source_ref не дедуплицируются.
- Chess-интеграция ограничена 5 blunder-карточками за игру, чтобы не
  перегружать очередь.

## 6. Риски

- Дубликаты Python-карточек при повторной неудаче не создаются; карточка
  не обновляется при смене теста.
- `due_at` в UTC; UI показывает локальное время.
- Retention считается по всем событиям, не по последнему ответу.
- Chess-анализ может создать карточки для blunder'ов соперника? Нет:
  `game.user_id` — владелец партии; blunder-ходы обоих цветов попадают в
  карточки, если анализ считает их ошибками.
- SM-2 при `hard` (q=3) не сбрасывает repetitions; интервал растёт медленно.
