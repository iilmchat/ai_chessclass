# Отчёт S-25 — PDF-отчёты родителям

**Дата:** 2026-11-01 · **Этап:** E-09 PDF и полировка · **Статус:** ✅

## 1. Что сделано

- Deps: `fpdf2>=2.8`; в образе **DejaVuSans** (fonts-dejavu-core) —
  кириллица в PDF; путь — `REPORTS_FONT_PATH`.
- Миграция `0014_reports`: `reports_pdfs` (student/requested_by/kind/path/
  size_bytes).
- `domains/reports/`: `pdf.py` (build_pdf: навыки 0–100 + Elo/счёт бота;
  generate_for_student — файл на volume `REPORTS_DIR` + запись в БД),
  `router.py` — `POST /reports/pdf/{student_id}` (201, teacher/admin) и
  `GET /reports/pdf/{id}` (application/pdf, inline).
- Тесты (+3): сборка с кириллицей (%PDF-магия), генерация+скачивание,
  RBAC (student → 403) и 404.

## 2. DoD

- [x] PDF по ученику генерируется ≤ 10 с — синхронно, < 0.5 с (fpdf2,
  без фона в v0.1; async-режим — при росте отчётов)
- [x] кириллица рендерится (DejaVuSans) — сборка и скачивание в тестах
- [x] pytest **147 passed** · ruff 0 · mypy 0 (147 файлов)

## 3. Что не сделано / блокеры

- Проза родителям через `reports.parent_summary` (L1) — маршрут готов в
  реестре; текст-абзацы — при первой партии/статистике (S-26+).
- Фоновая генерация (arq) — не нужна пока (< 1 с).

## 4. Отклонения от Design (нужны ADR?)

- Нет ADR. Порт §20.2 (fpdf2 + системный TTF) соблюдён; аннотатор
  использует Arial/DejaVu по PDF_FONT_PATH — у нас фиксированный DejaVu
  в образе (env переопределяет).

## 5. Новые факты → Design (обязаны вернуться в Design?)

- DejaVuSans из apt-пакета fonts-dejavu-core — воспроизводимый источник
  шрифта (не коммитим TTF) — SPEC §9 (reports).

## 6. Риски

- Файлы отчётов копятся на volume без чистки — retention 14 дней
  (cron-чистка) — E-10 полировка.
- Отчёт без judge-вердиктов и последних комментариев — контент расширится
  по мере доменов (сводка уже фактическая).
