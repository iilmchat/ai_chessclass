  (worker напрямую / api через arq) — переиспользуется S-12.

## 6. Риски

- Синхронное ожидание arq-результата (30 с) — при длинных gm-профилях и
  очереди может вылезти 408; наблюдаем, при необходимости — async-режим
  с SSE (задел task_id уже в коде).
- react-chessboard 5 API (`Chessboard options`) — тяжелее v4 на ре-рендерах;
  при拖 slow UI — мемоизация.
