# Отчёт S-07 — Песочница (порт executor)

**Дата:** 2026-11-01 · **Этап:** E-03 Python-домен · **Статус:** ✅

## 1. Что сделано

- `backend/sandbox/` (порт app/core из teacher, §20.1):
  - `runtime.py` — чистое ядро (без app-зависимостей): ALLOWED/FORBIDDEN
    модули, FORBIDDEN_CALLS, `find_violations` (AST), `run_restricted`
    (compile_restricted + safe_builtins + гварды + PrintCollector +
    safe input + RestrictedFeatureError для RP 8.x format-бана);
  - `limits.py` — `apply_memory_limit` (POSIX RLIMIT_AS; Windows Job Object
    — полный порт) + `truncate_output` (64 КБ + пометка);
  - `executor.py` — subprocess-раннер: свежий интерпретатор на запуск,
    JSON-протокол по stdin/stdout, per-run timeout (kill), статическая
    отсечка до spawn, async-обёртка (`asyncio.to_thread`).
- Зависимость `RestrictedPython>=8.5` в pyproject (образ пересобран).
- Config/env: `SANDBOX_MEMORY_LIMIT_MB=256`, `SANDBOX_MAX_OUTPUT_CHARS=65536`,
  `SANDBOX_TIMEOUT_S=5`.
- Тест-матрица атак `tests/sandbox/test_attacks.py` (29 тестов): импорты
  (os/subprocess/socket/threading/ctypes/from os import), eval/exec/compile/
  open, dunder-атрибуты, неизвестный модуль (сообщение со списком), math
  разрешён, recursion, .format → дружелюбная ошибка, stdin, обрезка вывода
  (in-process + executor), таймаут бесконечного цикла, memory spike через
  RLIMIT_AS, статическая отсечка без spawn.
- `tests/__init__.py` + `tests/sandbox/__init__.py` (пакет, чтобы
  tests/sandbox не затенял пакет `sandbox`); импорты conftest переведены
  на `from tests.conftest import`.
- SPEC: новый раздел §7 «Песочница» (слои, результат, коды ошибок, лимиты),
  история → §8.

## 3. Что не сделано / блокеры

- Батч-режим (один интерпретатор на N тест-кейсов) и пул тёплых воркеров —
  порт teacher S-23; понадобятся в S-08 (сдача задания = N тест-кейсов);
  контракт `run_sync/run` уже совместим.
- Контейнерный режим (`EXECUTOR_MODE=container`) — teacher S-24; для v0.1
  достаточно subprocess-изоляции + RLIMIT (одна машина, dev).

## 4. Отклонения от Design (нужны ADR?)

- Нет ADR. Все гарантии §13.2 реализованы как сформулированы; численные
  лимиты (256 МБ, 64 КБ, 5 с) — env-конфигурация, DESIGN-факт не менялся.

## 5. Новые факты → Design (обязаны вернуться в Design?)

- `RestrictedFeatureError` — дружелюбная подсказка про f-строки при попытке
  `.format()` (RP 8.x блокирует из-за GHSA-*) — перенесено из teacher в SPEC §7.
- `tests/` стал пакетом (причина: pytest перестал добавлять tests/ в
  sys.path; одновременно защита от затенения пакета `sandbox`) — процессная
  деталь, в Design не дублируется.

## 6. Риски

- RLIMIT_AS в контейнере ограничивает виртуальную память — некоторые C-библиотеки
  резервируют большие адресные пространства; при переносе numpy/matplotlib
  (E-05+) лимит может потребовать подъёма (настройка через env).
- Нет ограничения на количество параллельных запусков (§13.2 concurrency) —
  придёт вместе с arq-воркером сдачи (S-08), где естественно ограничить
  `max_jobs`.
