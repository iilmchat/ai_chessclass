# Отчёт S-53 — Генератор этюдов v2

**Дата:** 2026-11-03 · **Этап:** E-19 · **Ветка:** main (автономный режим)

## 1. Что сделано

- **Кандидаты.** Curated-база + random-playout из начальной позиции
  (8–30 полуходов, отбрасывание терминальных позиций).
- **Batch.** `generate_batch(count=1..20)`:
  - `exclude_fens` — дедупликация в рамках батча;
  - метрики `requested/created/skipped/defects/defectRate/uniqueFens`;
  - общий дневной лимит `study_daily_limit`.
- **Auto-review.** Проверка FEN, `solution_uci`, всей PV на легальность;
  результат в `generator_meta.autoReview`; invalid → `rejected`.
- **Сложность.** `engineDifficulty` по `score_cp` SF: ≥250 novice,
  ≥80 intermediate, иначе advanced.
- **Многоходовый solver.** `POST /studies/{id}/attempt-line`:
  - проверка линии/префикса PV;
  - `failedPly`, `nextUci`, сообщение;
  - старый `attempt` (первый ход) сохранён.
- **Метрики.** `GET /admin/studies/generator/metrics` — generated,
  autoReviewed, defects, defectRate, duplicateFens.
- **API.** `POST /admin/studies/generate-batch`; batch 201; audit
  generation.

## 3. Что не сделано / блокеры

- **Реальный SF** в API-роли недоступен (APP_ROLE=api): batch в проде
  должен идти через worker/arq; сейчас `run_engine_analysis` в API
  делегирует arq, что соответствует архитектуре.
- **Random-playout** может дать позиции без тактического мотива; SF
  валидирует только легальность/оценку, не «красоту».
- **UI батча/метрик** не делался: admin API/Swagger.
- **Дедупликация** только внутри батча; глобальные повторы FEN возможны
  между запусками (исторические данные).
- **Альтернативы** solver проверяет только основную PV, не все лучшие
  ходы из MultiPV.

## 4. Отклонения от Design

- Дедупликация в batch, а не глобальный unique-индекс FEN: не ломает
  существующие этюды/тесты и позволяет исторические повторы.
- Auto-review не меняет статус валидного этюда (остаётся draft); invalid
  сразу rejected.
- Сложность вычисляется по score, а не по depth/ELO; `engineDifficulty`
  сохраняется отдельно от curated `difficulty` (difficulty тоже обновлён).

## 6. Риски

- Random-playout FEN может быть слишком сложным/скучным; нужен ручной
  ревью учителя (статус draft).
- `defectRate` считается по autoReview, не по фактическому решению
  учениками.
- Batch 20 упирается в дневной лимит; повторный запуск в тот же день
  вернёт меньше.
- PV из SF может быть длиннее лимита 20 ходов; attempt-line ограничен 20.
