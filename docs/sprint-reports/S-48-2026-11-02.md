# Отчёт S-48 — Турниры v2: async, replay и античит

**Дата:** 2026-11-02 · **Этап:** E-17 · **Ветка:** main (автономный режим)

## 1. Что сделано

- **Схема.** Миграция `0023_tournament_v2`:
  - `tournaments`: `progress`, `total_matches`, `job_id`,
    `cancel_requested`, `error`; статусы `queued|running|done|cancelled|failed`;
  - `tournament_moves`: ply/fen/uci/agent (`a|b`)/`bot_version_id`/
    think_ms/`sf_sample`; индексы match/tournament.
- **Async-турнир.**
  - `create_tournament` создаёт `queued` и участников; API
    `POST /admin/tournaments` → **202** и enqueue arq
    `run_tournament_job` с `_job_id=tournament:{id}`.
  - `run_tournament_job`: bracket/round-robin, прогресс в БД, Redis pubsub
    `tournaments:{id}`, commit после каждого матча.
  - `GET /tournaments/{id}/events` — SSE status/progress
    (`running/done/cancelled/failed`).
  - Recovery: cron/startup `resume_tournaments` подхватывает
    `queued/running`; завершённые матчи не дублируются (идемпотентность).
  - Отмена: `POST /admin/tournaments/{id}/cancel`; job завершает между
    матчами.
- **Replay/seed/ничьи.**
  - Ходы пишутся в `tournament_moves`;
    `GET /tournaments/{id}/matches/{mid}/replay` — match + moves.
  - Seed задаёт порядок; в bracket ничья детерминированно решается по
    seed/id; round-robin ничья = 1 очко каждому.
- **Античит.**
  - 10 % ходов каждого бота помечаются `sf_sample`.
  - После турнира `engine_likeliness` считает top-1 rate по семплам;
    превышение порога → `AnticheatFlag(domain=bot, source_ref=tournament:{id})`.
  - Ошибка SF/античита не ломает турнир (warning).
- **UI `/tournaments`.**
  - Статус/progress/total, polling 2 с для queued/running, отмена,
    replay-кнопка и список ходов с SF-семплами.
- **Тесты.** `test_tournament_v2.py`: async bracket 8 ботов (7 матчей,
  14 ходов), replay, повторный запуск без дублей, cancel, SSE terminal.

## 3. Что не сделано / блокеры

- **SSE в UI** не подключён: фронт использует polling 2 с (SSE endpoint
  готов); polling — fallback, как в S-33.
- **SF-античит в тестах** не запускает реальный Stockfish: проверяются
  move-семплы/идемпотентность; реальный флаг зависит от worker/SF.
- **Денежный бюджет турнира** не отдельный: LLM в турнире не используется,
  ограничение — участники/ходы/время; при необходимости — конфиг.
- **Расписание/таймслоты** не делались: запуск сразу после enqueue.
- **Полный recovery после падения посреди матча**: незавершённый матч
  перезапускается (ходы не коммитятся до завершения матча); завершённые
  матчи сохраняются. Это осознанный компромисс.
- **Replay UI** показывает UCI-ходы, без доски/анимации.

## 4. Отклонения от Design

- Async API возвращает `TournamentOut` (queued), а не полный detail:
  детали подтягиваются polling/SSE.
- Ходы турнира хранятся отдельно от `bot_match_moves`, чтобы не искажать
  Elo/лестницу и не смешивать турнирный античит с обычными матчами.
- Recovery cron запускается на старте и в minute=5; job id защищает от
  дублей.
- Ничья в bracket решается seed/id (без дополнительных партий).

## 6. Риски

- 16 ботов round-robin = 120 матчей; async снимает блокировку API, но
  worker занят долго — нужен отдельный queue/лимит при росте.
- Recovery после падения посреди матча перезапускает матч; при
  недетерминированных ботах результат может отличаться.
- SF-античит может дать false positive на сильных ботах; порог/ревью
  учителем, флаг не блокирует.
- `cancel_requested` проверяется между матчами, не внутри матча.
- Replay хранит все ходы; retention для `tournament_moves` пока нет.
