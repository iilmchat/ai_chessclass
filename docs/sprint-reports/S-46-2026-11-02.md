# Отчёт S-46 — Retention, наблюдаемость и стоимость

**Дата:** 2026-11-02 · **Этап:** E-17 · **Ветка:** main (автономный режим)

## 1. Что сделано

- **Схема.** Миграция `0022_observability`: `voice_usage`
  (`user_id`, `chars`, `cost`, `cached`, `created_at`) — фактическое
  использование озвучки, включая cache-hit (cost=0), для cost-per-student.
- **Retention (`domains/retention/service.py`).**
  - Политики: `audit_logs` 365 дн., `llm_calls` 180, `voice_audio`/`voice_usage`
    30, draft/rejected `chess_studies` 90.
  - Перед удалением — gzip-JSONL архив в `RETENTION_ARCHIVE_DIR`; для
    voice-аудио удаляются и файлы; published studies сохраняются.
  - Dry-run без записи/удаления; batch-лимит; worker cron **04:10 UTC**;
    запись `retention.run` в audit_logs.
- **Наблюдаемость.**
  - `GET /metrics` (Prometheus text): DB/Redis, глубины очередей, active
    матчи, LLM/voice cost/tokens, свободный диск; `METRICS_TOKEN`.
  - `GET /admin/observability/summary` — health/очереди/расход/диск/retention.
  - `GET /admin/observability/alerts` — DB/Redis, диск, очередь, LLM-cost,
    TLS (<30 дн., если задан `OBS_TLS_CERT_PATH`), устаревший retention.
  - `GET /admin/observability/costs?days` + `costs.csv` — LLM + voice
    по ученикам, итог; admin.
  - `GET /admin/observability/retention/status`, `POST .../retention/run`
    (`dryRun`) — admin.
- **UI `/ops`.** Инфраструктура/расход/очереди/алерты, retention dry-run/
  запуск, таблица стоимости, `costs.csv`.
- **Prod.** Volume `chessclass_archive`; env `*_RETENTION_DAYS`,
  `RETENTION_ARCHIVE_DIR`, `OBS_*`, `METRICS_TOKEN`.
- **Тесты.** `test_retention.py` (архив/удаление, published сохранён,
  dry-run), `test_observability.py` (summary/alerts/costs/CSV/retention/
  metrics/token).

## 3. Что не сделано / блокеры

- **Prometheus Alertmanager/Grafana** не подняты в этом репозитории: API
  отдаёт метрики/алерты, интеграция с внешним мониторингом — infra-задача.
- **Retention обрабатывает одну batch-порцию за запуск** (10k); при больших
  объёмах нужен цикл/несколько запусков.
- **TLS-алерт** работает только если `OBS_TLS_CERT_PATH` доступен из API
  (в текущем prod certs смонтированы только в edge); в runbook указано.
- **voice_usage cache-hit** пишет cost=0 и chars (факт запроса), но не
  размазывает стоимость кэша по пользователям; для v0.3 приемлемо.
- **Retention архивы** не ротируются/не уезжают offsite; это отдельная
  инфраструктурная задача.

## 4. Отклонения от Design

- `voice_usage` добавлен отдельно от `voice_audio`: кэш глобальный, а
  стоимость/использование — per-user.
- Retention удаляет `llm_calls`, но `usage_daily` (агрегаты) сохраняется.
- `/metrics` по умолчанию без auth; в prod рекомендуется `METRICS_TOKEN`
  и внутренний scrape (edge не проксирует `/metrics`).
- UI `/ops` доступен admin/auditor; teacher видит только свои домены.

## 6. Риски

- Архив gzip на том же диске не защищает от отказа диска; нужен offsite.
- Retention может удалить нужные для расследования audit-логи, если
  политика слишком короткая; значения вынесены в env.
- `METRICS_TOKEN` пуст по умолчанию — в prod обязательно задать/ограничить
  сеть.
- Стоимость voice зависит от корректного `VOICE_COST_PER_1K_RUB`; при 0
  дашборд покажет 0.
- Алерты — pull/endpoint, без push-уведомлений.
