## 1. Что сделано

- `backend/bot_lab/replay.py`: `get_replay` (метаданные + ходы по порядку),
  `leaderboard` (top-N по Elo), `match_progress_payload` (разбор pubsub).

  pubsub `bots:match:{id}` (done — конец потока).
- UI BotsPage: редактор кода бота (textarea; код-редактор с подсветкой —
  замена при полировке), тест-ход, матч vs random (polling результата
  через 20 с — вместо SSE в UI; SSE API готов), реплей (список ходов
  с agent/think_ms), лидерборд, свой рейтинг.
