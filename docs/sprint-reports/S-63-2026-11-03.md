# Отчёт S-63 — Ворота CI: security / a11y / load / docker / backup

**Дата:** 2026-11-03 · **Этап:** E-22 Edge, supply chain и ворота CI · **Статус:** ✅

## 1. Что сделано

- **`.github/workflows/ci.yml`:**
  - backend job: шаг **pip-audit** по hash-lock
    (`pip-audit -r requirements.lock --timeout 90`, дефолтный pypi-сервис —
    на runner'е pypi.org открыт; локальная сеть его блочит, см. S-62);
  - e2e job: шаг **«Backup → restore smoke»** —
    `scripts/ci/backup_smoke.sh` (bash-порт restore-test.ps1): pg_dump →
    sha256 → restore во временную `chessclass_restore` →
    `users>=1` + `alembic=0028_rag_editor` → drop temp.
  - новые job'ы: **`secrets`** (gitleaks action, fetch-depth 0 — вся
    история) и **`images`** (docker build `./backend` hash-lock и
    `./frontend` CSP-enforce).
- **`.github/workflows/load.yml`** (новый): cron `0 4 * * 1` (пн) +
  `workflow_dispatch`; стек как у e2e (API 8021 + 4 match-воркера,
  LLM echo), прогон `scripts/load_smoke.py --requests 100 --concurrency 20
  --p95-ms 200 --include-ready` → **p95 публикуется в GitHub Step Summary**
  (markdown-таблица) + артефакт логи при падении.
- **a11y-ворота** — `frontend/e2e/a11y-axe.spec.ts`: axe-core читается из
  node_modules (файл, без CDN; bypass CSP не нужен — dev-сервер), тест
  гоняет 5 публичных маршрутов (`/`, `/python`, `/chess`, `/bots`,
  `/skills`) на wcag2a+wcag2aa; blocking = critical/serious; список
  нарушений печатается перед падением. Полный a11y-чеклист — S-66.
- axe-core добавлен в devDeps (`axe-core@^4.14.0`).
- Gate-матрица — ниже (§5).

## 3. Что не сделано / блокеры

- Первый **CI-прогон после push** — единственный недоказанный факт
  (все ворота локально исполнимы, кроме gitleaks action / pip-audit на
  pypi-сервис); при первом красном job'е — правки в ответ, не блокер.
- Подключение `match_load.py` (матчи/LLM-профили) в load.yml — S-69
  (profiling командами после деплоя staging; сейчас health/ready-профиль).

## 6. Риски

- axe `color-contrast` на Vite dev-странице может давать ложные срабатывания
  (HMR-оверлей/динамические темы) — первый CI-прогон покажет; при
  подтверждении — фикс стилей или S-66-правка критерия.
- gitleaks-action@v2 может давать false positives на JSON-схемах/примерах;
  `.gitleaks.toml` allowlist добавим при первом ложном срабатывании.
- load-smoke 100/20 — up c прошлых «30/5»; для service-контейнеров GH
  runner'а — посильная нагрузка.
