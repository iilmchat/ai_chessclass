# Отчёт S-54 — RAG/контент-редактура

**Дата:** 2026-11-03 · **Этап:** E-19 · **Ветка:** main (автономный режим)

## 1. Что сделано

- **Схема.** Миграция `0028_rag_editor`:
  - `rag_documents.license/status/version/updated_at`;
  - `rag_document_versions` (история, created_by).
- **Редактор.** `POST/GET /admin/rag/documents`, `PATCH`, publish/archive,
  versions, rollback; teacher/admin. Draft не виден в retrieval; публикация
  включает; rollback восстанавливает старую версию и создаёт новую.
- **Гибридный поиск.** 0.7×cosine + 0.3×`ts_rank_cd('russian')`, фильтры
  domain/status; `mode=vector` — baseline. `GET /admin/rag/eval` сравнивает
  baseline/hybrid и возвращает passed.
- **Импорт.** `POST /admin/rag/import` (base64) для `.md/.markdown/.txt/.pdf`;
  PDF через `pypdf`; source=filename, license сохраняется.
- **Версии/лицензии.** API отдаёт version/status/license, versions list;
  UI не делался (Swagger/API).
- **Ingest.** Старый ingest также пишет версию 1 и license; совместим с
  существующими тестами.

## 3. Что не сделано / блокеры

- **UI редактора** не делался: admin/teacher API/Swagger.
- **Eval** — 3 эвристических кейса, не полноценный gold-set; метрика
  top-5 substring, не nDCG.
- **PDF-импорт** зависит от `pypdf` (добавлен в зависимости); сканы без
  текстового слоя не OCR-ятся.
- **Публикация** не требует ревью второго человека; teacher может сам
  опубликовать.
- **Импорт** принимает base64 JSON, а не multipart-файл; лимит размера
  задаётся прокси/JSON-парсером.

## 4. Отклонения от Design

- Версии хранятся отдельной таблицей с полным снимком, а не diff.
- Rollback сразу публикует восстановленную версию (version+1).
- Гибридный вес фиксирован 0.7/0.3; настройка не вынесена в env.
- `updated_at` есть в БД, но не отдаётся в DocumentOut (created_at/version
  достаточно; избегаем lazy-load после commit).

## 6. Риски

- FTS `plainto_tsquery` зависит от русской конфигурации PostgreSQL; в
  нестандартной БД может не найти лексемы.
- Hash-эмбеддинги в dev слабее реальной модели; eval может отличаться.
- Draft-документы занимают чанки/эмбеддинги; при откате/удалении каскад.
- pypdf не извлекает текст из сканов; нужен OCR.
- Импорт больших PDF может превысить память/JSON-лимит.
