# Отчёт S-18 — Матчи и Elo (лестница-часть 1)

**Дата:** 2026-11-01 · **Этап:** E-07 Лаборатория ботов · **Статус:** ✅

## 1. Что сделано

- Миграция `0012_bot_matches`: `bot_stats` (elo Numeric, wins/losses/draws),
  `bot_matches` (version_id/opponent/result CHECK/moves_count/duration_ms/
  elo_delta/finished_at), `bot_match_moves` (реплей: ply/fen/uci/agent/
  think_ms, sf_sample — задел S-19).
- `opponents.py` — trusted-модули воркера: random (≈400), greedy (≈800,
  материал-дельта), minimax2 (≈1100, negamax глубина 2 + alpha-beta).
- `elo.py` — K=32, clamp ±40 (ADR-008); `match.py` — матч-луп: ученик через
  песочницу (per-move 1.0 c), оппонент напрямую; MAX_PLIES=60, бюджет 120 с;
  нарушения ученика → немедленное поражение/таймаут; прогресс — pubsub
  `bots:match:{id}`.
- arq-задача `run_match`; API: `POST /bots/{id}/match/run` (202), `GET
  /bots/{id}/matches`, `GET /bots/stats` (старт 1000).
- Тесты: elo_delta (win/loss/draw/clamp), матч vs random до конца (ходы ≤60,
  записи в БД, stats-эндпоинт, история матчей).

## 2. DoD

  result ∈ win/loss/draw, plies ≤ 60, elo обновлён
- [x] Elo: K=32, clamp ±40 — юнит-тест elo_delta
- [x] pytest **135 passed** · ruff 0 · mypy 0 (130 файлов)

## 3. Что не сделано / блокеры

- SF-оппоненты (UCI_Elo 1400/1600/1800) и семплирование ходов — S-19.
- SSE-прогресс матча — pubsub-канал готов; SSE-эндпоинт — S-20 (вместе
  с реплеем и Elo-графиком).

## 4. Отклонения от Design (нужны ADR?)

- Нет ADR. Ученик всегда белыми (v0.1; §7.4 чередование — v0.2) — отмечено
  в SPEC §3.10.

## 5. Новые факты → Design (обязаны вернуться в Design?)

- Порядок маршрутов: `/bots/stats` объявлен раньше `/{bot_id}` (иначе
  «stats» матчится как bot_id → 422) — процессная деталь, SPEC §3.10.

## 6. Риски

- Per-move subprocess (~0.3–0.5 с накладных): матч 60 ходов ≈ 30–60 с +
 思考 время — в бюджет 120 с укладывается, но длинные партии ученика
  упрутся в таймаут (это фича: поражение по бюджету §7.2).
- concurrency матчей (§7.2: 2) — пока не ограничивали; при очередях arq
  добавить max_jobs/trasync — S-19.
