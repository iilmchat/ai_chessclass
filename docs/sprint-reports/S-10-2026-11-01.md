# Отчёт S-10 — Engine wrapper (порт)

**Дата:** 2026-11-01 · **Этап:** E-04 Шахматный домен · **Статус:** ✅

## 1. Что сделано

- `backend/engine/` (порт app/engine annotator — почти verbatim):
  - `service.py` — EngineService + _UciEngine: async UCI (handshake
    uciok 15 с, readyok 5 с, поиск movetime + 4 с чтения, kill+restart при
    зависании), профили beginner/club/gm (12/18/28 depth, 1/3/5 multipv,
    200/1000/5000 мс), **интерактивный clamp** ≤ `SF_INTERACTIVE_MOVETIME_MS`,
    **UCI_Elo** (UCI_LimitStrength, диапазон 1320..3190), Threads/Hash из env,
    валидация FEN через python-chess, гвард **«SF — только worker»**
    (`APP_ROLE=worker` — §15.3);
  - `models.py` — EngineLine (multipv/depth/score_cp/mate/move_uci/pv,
    мат = ±(10000−100·N));
  - `errors.py` — EngineError/NotFound/Timeout/Forbidden.
- Dockerfile: **Stockfish 17.1 (ubuntu avx2)** — официальный релиз в образ
  (BuildKit heredoc + urllib + tar); путь `/usr/local/bin/stockfish`.
- Config/env: STOCKFISH_PATH, SF_THREADS=1, SF_HASH_MB=16,
  SF_INTERACTIVE_MOVETIME_MS=1000, APP_ROLE=api|worker (compose worker
  получает APP_ROLE=worker).
- Deps: `chess>=1.10` (python-chess).
- Интеграционные тесты `tests/test_engine_integration.py` (+8, skip если
  бинарника нет): стартовая позиция (bestmove/eval/depth), мат в 1
  (Re8#), interactive-clamp gm-профиля, UCI_Elo 1400 + вне диапазона,
  кривой FEN, гвард роли, профили.

## 4. Отклонения от Design (нужны ADR?)

- Нет ADR. Профили взяты из SPEC annotator (§2.2) — Design §7 фиксирует
  только принципы. SF 17.1 вместо «Stockfish 17» — минорная версия релиза,
  факт зафиксирован в SPEC §9 и README-стеке при апдейте.

## 5. Новые факты → Design (обязаны вернуться в Design?)

- APP_ROLE (api|worker) — механика правила «SF — только worker» (env-роль
  процесса); дизайн-факт тот же, реализация зафиксирована в SPEC §9.
- SF 17.1 ubuntu-x86-64-avx2 — точный артефакт образа (R-01-стиль:
  версия движка важна для кэша линий — S-11 учтёт `id name`).

## 6. Риски

- Скачивание SF при build — зависимость от GitHub releases (сеть CI/хоста);
  при сбоях — кэш образов/docker layer или локальная установка через
  scripts (fallback на apt stockfish 16 — потеря R-фактора точности).
- avx2 требуется на CPU — стандарт для 2013+; на редком железе нужен
  другой билд (ssse3) — вариант ссылки в Dockerfile по запросу.
