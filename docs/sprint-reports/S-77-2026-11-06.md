## 3. Что не сделано / блокеры

Блокеров нет.

Ограничения:

- **Профиль observability не стартует по умолчанию**: нужен явный
  `--profile observability`, чтобы не занимать ресурсы в обычном dev.
- **Нет Alertmanager/Telegram-доставки** для Prometheus-правил: алерты
  видны в Prometheus/Grafana, но не маршрутизируются наружу.
- **Метрики process-local**: при нескольких uvicorn-процессах Prometheus
  должен скрейпить каждый инстанс; агрегация — на стороне Prometheus.
- **Tempo без постоянного storage и TLS/auth**: 24h retention, локальный
  volume; для prod нужен S3/retention policy и защита.
- **Grafana admin пароль по умолчанию `admin`** в dev; в staging/prod
  задавать `GRAFANA_PASSWORD`/внешний auth.
- **Collector без TLS**: OTLP доступен только во внутренней сети/loopback;
  для межсетевого доступа нужен mTLS.

## 4. Отклонения от Design (нужен ADR?)

- **HTTP p95 считается по process-local histogram в приложении**, а не
  через OTel spanmetrics/collector. Это проще и не добавляет зависимостей;
  контракт метрик зафиксирован в SPEC.
- **Prometheus-правила — алерты, но без Alertmanager**: доставка уведомлений
  остаётся ops-задачей; отдельный ADR не нужен.
- **Collector/Tempo/Grafana — профиль, не дефолт**: снижает нагрузку dev/CI.
- Новый ADR не требуется.

## 6. Риски

- **Кардинальность route**: путь без шаблона может дать много series;
  сейчас route берётся из FastAPI route, но при 404 — raw path.
- **Потеря traces**: Tempo 24h и отсутствие persistent volume; при рестарте
  история теряется.
- **Шум алертов**: p95/5xx правила могут срабатывать на нагрузке; нужен
  Alertmanager с inhibit/группировкой.
- **Безопасность Grafana**: дефолтный пароль и отсутствие TLS недопустимы
  в prod; закрывать loopback/VPN.
- **Collector memory limit 256 MiB** может отбрасывать спаны при всплеске;
  настроить очередь/батчи под нагрузку.
- **Секреты в OTLP**: атрибуты не должны содержать prompt/PII; сейчас
  спаны содержат route/model/status, но не текст запроса.
