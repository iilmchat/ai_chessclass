**Дата:** 2026-11-01 · **Этап:** E-03 Python-домен · **Статус:** ✅ (этап завершён)

## 1. Что сделано

- Миграция `0006_py_hints_cognitive`: `py_reference_solutions`,
  `py_feedback`, `anticheat_flags` (§9.4: kind/domain/source_ref/confidence/
  evidence/status/reviewed), `cognitive_skill_events` (§10.2).
- Лестница (§5.4): `POST /py/assignments/{id}/hint` — seeded ступени
  (`py_hints`), по исчерпании — LLM через `python_teacher.hint` (правила
  уровня prompt_builder'а); `GET .../solution` — эталон после 3 неудач
  (учителю — всегда), иначе `403 solution_locked`.
- Комментарий к сдаче: `submit` возвращает `feedback` (маршрут comment,
  L1/L2 по уровню из профиля; в dev — echo); сохранение `py_feedback`
  (уникален на сдачу); сбой комментария не ломает сдачу.
- Античит-заготовка: `low_effort` (tiny_code ≤3 строк → 0.60;
  starter_unchanged_repeat → 0.80) — флаг с evidence, не блокирует (§9.1).
- События навыков: submit passed +1.0 / failed +0.3; подсказки −0.5/−1.0;
  решение −2.0 (эмитятся только student; отсутствие навыка → skip+warning).
- Seeds: +16 эталонных решений с backfill'ом по существующим заданиям.
- SPEC: §3.4 (ladder), §8 (античит + веса событий), §2 (эндпоинты), история.
