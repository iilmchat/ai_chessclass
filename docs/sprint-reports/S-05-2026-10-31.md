# Отчёт S-05 — Экономика: llm_calls, бюджеты, fallback

**Дата:** 2026-10-31 · **Этап:** E-02 LLM-шлюз (завершается) · **Статус:** ✅

## 1. Что сделано

- Миграция `0004_llm_economy`: `llm_calls` (журнал: route/level,
  model_requested/model_used, fallback_from, tokens, cost_in/out
  Numeric(12,4), latency_ms, status CHECK ok|echo|error, task_kind
  CHECK sync|async) + `usage_daily` (PK user_id+day, upsert-инкремент).
- `llm/economy.py`: `check_quota` (Redis `quota:{user}:{date}`, бюджеты
  free 50k / pro 500k из config), graceful downgrade тир → L1 (оценка
  входа ~4 симв/токен), `compute_cost` (₽/1M), `register_call`
  (llm_calls + usage_daily + INCRBY квоты, TTL 48 ч), `finops_daily`.
- `llm/gateway.py` — переработан в `llm_generate(session, redis, …)`:
  fallback-цепочка cloud → local (флаг `LLM_LOCAL_FALLBACK`) → echo,
  каждый вызов записывается; `LLMCallContext` (user_id, billing_tier,
  task_kind); провайдеры — lazy-синглтоны, закрытие в lifespan.
- `llm/echo.py` — EchoProvider («промпт + факт-константа», 0 токенов).
- `llm/models.py` — ORM обеих таблиц; реестр db подключён (alembic autogen).
- API: `GET /api/v1/admin/finops/usage?days=7` (admin) — агрегат по дням.
- Тесты (+7): запись вызова+квота+usage_daily; исчерпание → echo
  (облако не вызывается); downgrade до L1 у границы бюджета; judge
  zero-квота; fallback на local (lmstudio); FinOps-эндпоинт + 403.

## 4. Отклонения от Design (нужны ADR?)

- Нет ADR. Уточнения контракта — SPEC §6.4: набор причин `fallback_from`
  (Design задал только факт поля), день квоты — UTC, echo не инкрементирует
  квоту и не пишет usage_daily (нулевые токены).

## 5. Новые факты → Design (обязаны вернуться в Design?)

- Оценка входных токенов для downgrade — эвристика 4 симв/токен (деталь
  реализации; при подключении реального провайдера можно заменить на
  счётчик токенизатора).
- FK llm_calls.user_id = SET NULL (журнал переживает удаление юзера),
  usage_daily — CASCADE (агрегат уходит вместе с юзером) — соответствует
  типовой журнальной семантике; отражено в SPEC §6.4.

## 6. Риски

- Лимит параллельности LLM-запросов (§12.3: 10 req/min/user) — ещё не
  реализован (глобальный 120/min тоже); закрывается вместе с доменами
  или отдельным маленьким спринтом.
- Echo-текст — dev-заглушка; в прод-обучении echo должен деградировать в
  понятное сообщение («ассистент временно недоступен») — правка тривиальна,
  сделаем при первом прод-подходе (E-10).
