# Отчёт S-44 — Озвучка ответов (ElevenLabs)

**Дата:** 2026-11-02 · **Этап:** E-16 · **Ветка:** main (автономный режим)

## 1. Что сделано

- **Схема.** Миграция `0020_voice`: `voice_audio` (`text_hash` unique,
  `voice_id/model_id`, `path`, `chars`, `cost`, `provider`, `created_at`);
  prod-volume `chessclass_voice`.
- **Провайдер.** `domains/voice/service.py`:
  - ElevenLabs `POST /v1/text-to-speech/{voice_id}` (`xi-api-key`,
    `model_id`), таймаут `VOICE_TIMEOUT_S`;
  - ключ не логируется; ошибка провайдера → 502.
- **Кэш.** Ключ `sha256(voice|model|text)`, файл в `VOICE_CACHE_DIR`,
  запись `voice_audio`; повторный запрос читает файл и **не вызывает**
  провайдера; кэш-хит аудитируется с `cached=true`.
- **Квоты/стоимость.** Redis `voice:chars:{user}:{UTC-date}` ≤
  `VOICE_DAILY_CHARS` (429 `voice_quota`); `cost` =
  chars/1000 × `VOICE_COST_PER_1K_RUB` (Numeric).
- **API.** `GET /voice/status` → configured/provider/model/voice;
  `POST /voice/speak { text, voiceId? }` → `audio/mpeg` + headers
  `X-Voice-Cached/Chars/Id`.
- **Fallback.** Пустой `VOICE_API_KEY` → 503 `voice_unavailable`; UI
  `VoicePlayer` показывает мягкую ошибку, текст остаётся доступным.
- **UI.** `VoicePlayer` в инсайте ChessPage, объяснении блюндера и
  инсайте дашборда; Blob-URL с очисткой.
- **Тесты.** `tests/test_voice.py`: кэш (provider вызван 1 раз), квота,
  fallback без ключа, `/voice/status`/`/voice/speak` 503.

## 3. Что не сделано / блокеры

- **Реальный ElevenLabs-ключ** не предоставлен: live-синтез не проверялся;
  тесты используют fake provider. Без ключа приложение работает в тексте.
- **Точная стоимость ElevenLabs** не зашита: `VOICE_COST_PER_1K_RUB=0`
  по умолчанию; для FinOps нужно заполнить тариф и, возможно, отдельный
  `voice_calls`/usage-отчёт.
- **Квоты по тарифам** (free/pro) не различаются: один дневной лимит;
  можно расширить в S-45/после.
- **Очистка кэша/retention** не реализованы: файлы растут; нужен cron
  (аналогично audit_logs).
- **UI-плеер** не тестируется Playwright; только build/TS. E2E озвучки
  требует ключа и не входит в CI.

## 4. Отклонения от Design

- Озвучка — отдельный HTTP-провайдер, не LLM-маршрут gateway: другая
  цена/квота и бинарный ответ; `voice.speak` — имя операции.
- `POST /voice/speak` возвращает аудио напрямую (Blob), а не URL: проще
  авторизация (Bearer), не нужен публичный audio-route.
- Кэш глобальный (voice+model+text), не per-user: один и тот же текст
  озвучивается один раз для всех — экономия.

## 6. Риски

- Кэш без retention может занять диск; нужен cron/лимит.
- При утечке `VOICE_API_KEY` — расход; ключ только в `.env`, ротация.
- Blob-URL в браузере живёт до revoke/перезагрузки; утечки памяти
  минимальны, но при частых кликах — очистка есть.
- Один глобальный кэш может раскрывать факт озвучки одинакового текста
  (не PII); для v0.2 приемлемо.
- Стоимость 0 по умолчанию может скрывать расходы — заполнить тариф.
