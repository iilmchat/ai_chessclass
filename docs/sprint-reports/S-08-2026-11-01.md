# Отчёт S-08 — Задания и сдача

**Дата:** 2026-11-01 · **Этап:** E-03 Python-домен · **Статус:** ✅

## 1. Что сделано

- Миграция `0005_py_domain`: `py_assignments` (slug uq, level CHECK, topic →
  slug навыка, tests JSONB), `py_hints` (лестница 4 видов, uq assignment+idx),
  `py_submissions` (verdict CHECK passed/failed/timeout/restricted/error).
- `domains/python_teacher/`:
  - `grader.py` — батч-прогон: решение + сгенерированный harness
    (try/assert с маркерами) в один процесс песочницы; **маркеры солятся
    per-run** (ученик не может напечатать фейковый PASS); парсинг →
    вердикт/failed_test/stdout_digest (вывод ученика без маркеров);
  - `service.py` — CRUD (admin, валидация тестов: однострочные, assert),
    submit (прогон → сохранение), приватность сдач (свои или teacher/admin);
  - `router.py` — 6 эндпоинтов `/api/v1/py` (Design §12.2); тесты задания
    ученику не отдаются (только testsCount).
- Seeds: `db/seeds_tasks.py` — **16 заданий** (переменные → условия → циклы →
  вложенные циклы → списки/срезы → функции → алгоритмы; novice/intermediate/
  advanced) + 18 ступеней подсказок; интегрированы в `seed`.
- Фронтенд: `PythonPage` — вход (dev-форма), список заданий, экран задания
  (условие, редактор, «Проверить»), вердикт-панель; `shared/api.ts` —
  access-token (localStorage) + Bearer + DTO python-домена; стили редактора.
- `PageOut` перенесён в `core/base` (пагинация — общий контракт).

## 4. Отклонения от Design (нужны ADR?)

- Нет ADR. Уточнения контракта — SPEC §3.3: slug задания (ключ сидов,
  сверх каталога), солёные маркеры grader (безопасностное усиление),
  приватность сдач (свои/teacher-admin).

## 5. Новые факты → Design (обязаны вернуться в Design?)

- RP запрещает имена с ведущим underscore (`except … as _exc` → SyntaxError) —
  harness использует `cc_e`. Урок: генерируемый код для песочницы не должен
  содержать `_`-имён и dunder-атрибутов (дважды поймано статикой:
  `type(_exc).__name__` тоже блокируется).
- PageOut — общий контракт (core/base) вместо дублей в доменах.

## 6. Риски

- Ученический print рядом с маркерами — парсер фильтрует по соли; при
  огромном выводе ученика обрезка 64 КБ может съесть хвост маркеров —
  счётчик passed/failed ведём по встреченным маркерам, FAIL-ветка не теряется
  (маркеры идут после каждого теста; наблюдаем на реальных сдачах).
- Seeds с f-string-решениями — тесты в JSONB с кавычками: проверено
  прохождением сидов и сдачи.
