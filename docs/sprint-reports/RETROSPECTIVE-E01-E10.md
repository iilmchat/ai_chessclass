# Ретроспектива этапа v0.1.0 (S-01…S-29)

**Дата:** 2026-11-01 · Спринтов завершено: **29/29**

## Что прошло хорошо

- **Вертикальные срезы** — каждый спринт закрывал полный срез (DDL → код →
  API → тесты → документация), демо после каждого этапа.
- **Порт проверенного кода** (teacher/annotator) — runtime песочницы,
  engine-wrapper, prompt_builder перенесены почти verbatim; тест-матрицы
  из исходных проектов отсеяли баги до прогона.
- **Единый шлюз с квотами/фолбэком** — echo-режим дал полный пайплайн
  в dev без ключа (все E2E-тесты ходят через него).
- **Статические отсечки** (AST-анализ до spawn, белые списки) — матрица
  атак 20+ эксплоитов блокируется.
- **Документация по ходу** — SPEC/RULES/CHANGELOG/отчёты актуальны
  на момент каждого коммита.

## Что было трудно / повторяющиеся грабли

1. **Смешанные алфавиты** — кириллические буквы внутри латинских слов
   (известная особенность набора) ловились grep-аудитом в каждом спринте;
   после S-13 аудит-регекс уточнён (lookbehind на `\`-escape).
2. **RP `_`-имена** — трижды генерируемый код ломался о запрет имён
   с ведущим underscore; правило теперь в RULES §2.
3. **Пулы/loop'ы pytest** — engine/asyncpg привязка к event-loop; фикс —
   dispose между тестами.
4. **FastAPI-порядок маршрутов** — `/stats` объявлять до `/{bot_id}`
   (перехват).
5. **«Commit до raise»** — side-effect'ы (отзыв сессий, флаги) должны
   коммититься до AppError, иначе get_session откатывает.
